# Personal Finance Manager Frontend

Angular frontend for the Personal Finance Manager.

See the [project README](../README.md) for prerequisites, MongoDB and backend setup, API configuration and first-use instructions.

Run these commands from this directory:

```sh
npm ci
npm start
```

Open http://localhost:4200 after starting the backend.

```sh
npm run build
npm test -- --watch=false
```

Transaction dates, budget months and dashboard navigation support years 2000 through 2100.
